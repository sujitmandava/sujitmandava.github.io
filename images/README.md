# Images

Drop files here with these exact names; the page picks them up automatically.
Until a file exists, a labeled placeholder box is shown in its place.

| File | Used for | Suggested size |
|---|---|---|
| `portrait.jpg` | Hero photo (arched frame) | 800×1000 (4:5) |
| `school-1.png`, `school-2.png` | Education logos | 200×200, transparent PNG |
| `relativity.png`, `hgrid.png` | Experience logos | 200×200, transparent PNG |
| `wren/logo.png` | Wren logo | 256×256, transparent PNG |
| `wren/shot-1.png` … `shot-3.png` | Wren screenshots (1 is the large one) | 1600×1000 (16:10) |
| `cellar/logo.png` | Cellar logo | 256×256 |
| `cellar/shot-1.png` … `shot-3.png` | Cellar screenshots | 1600×1000 |
| `safewatch/logo.png` | SafeWatch logo | 256×256 |
| `safewatch/shot-1.png` … `shot-3.png` | SafeWatch screenshots | 1600×1000 |

Screenshots are cropped from the top, so put the most important UI there.
Want a different extension (e.g. .jpg/.webp)? Change the matching `src` in index.html.
